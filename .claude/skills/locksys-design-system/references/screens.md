# أنماط الشاشات

كل نمط مبني من مكونات `widgets.dart` فقط. ابدأ من الأقرب لشاشتك. المرجع البصري لكل نمط في `assets/design-system/index.html`.

## تدفق التشغيل الأول
`Splash (2.6s)` → `Onboarding (3 شاشات، أول مرة فقط)` → `كود الشركة (حتى يُحفظ كود صحيح)` → `Login` → `الرئيسية`.
مركّب في `lib/app.dart`. `onboarding_done` محفوظ في SharedPreferences، ومن المرة التانية يروح من Splash للدخول مباشرة (لإعادة رؤية الترحيب: امسح بيانات التطبيق).

### Splash — `SplashPage`
**خلفية بيضاء** (اللوجو الرسمي فيه جزء كحلي ما يظهرش على الكحلي). Pattern L ناعم بتلاشي دائري. اللوجو (`AppLogoMark` 120) يطلع بـ Fade + Scale(.88→1) + Slide، ثم "LockSys HR" (LTR) وتحته "الموارد البشرية / HUMAN RESOURCES"، وشريط تقدم أزرق رفيع 120×3، ورقم الإصدار. يستدعي `onFinished` مرة واحدة بعد 2.6s (أو انتظر التهيئة الفعلية لو أطول).

### Onboarding — `OnboardingPage`
- **3 شاشات كحد أقصى**، فكرة واحدة لكل شاشة (الحضور، الطلبات، الراتب والأمان).
- الصف العلوي: **لوجو صغير (32)** في البداية، وفي النهاية **`AppLanguageToggle`** ثم "تخطي" (يختفي في الأخيرة).
- ثم: رسم توضيحي (يمتد) ← عنوان 26 ← وصف سطرين ← نقاط (النشطة 28 عرض) ← زر `lg` ("التالي" ثم "ابدأ الآن").
- الرسم مبني من مكونات الهوية (كروت، شارات، مربعات أيقونات، عناصر عائمة تتحرك 6px) فوق Pattern وعلامة L كبيرة بشفافية 18%. **لا صور جاهزة.** كل نصوص الرسم من الترجمة (`art*`).
- لإضافة/تعديل شاشة: أضف مفاتيح `onbNTitle/onbNDesc` في الـ ARB ودالة `_xxxArt(w, h, l)`.

## كود الشركة — `CompanyCodePage`
التطبيق متعدد الشركات: كل شركة لها سيرفر ومزايا. الشاشة دي بتظهر **مرة واحدة** بعد الترحيب وقبل الدخول، ولا تظهر تاني بعد ما يتحفظ كود صحيح على الجهاز.
- **الشكل:** نفس Hero شاشة الدخول (`AppBrandHero`)، ثم Kicker "الخطوة الأولى" + H1 "كود الشركة"، حقل الكود (أيقونة `building`، `mono`، حروف كبيرة تلقائيًا، حروف وأرقام و`-` `_` فقط) مع سطر تلميح، ثم زر `lg`، ثم ملاحظة "ليس لديك كود؟" (كارت Blue50 بأيقونة help).
- **الحالات:** `idle` (زر "تحقق من الكود") ← `checking` (زر `loading`، الحقل معطّل) ← `found` (علامة صح خضراء في الحقل + كارت التعريف + الزر يصير "متابعة"). الخطأ: "أدخل كود الشركة" (فارغ) · "كود الشركة غير صحيح" تحت الحقل (يختفي التلميح) · انقطاع الاتصال = `AppAlert` أحمر والزر يصير "إعادة المحاولة". تعديل الكود بعد النجاح أو الخطأ يرجّع الحالة `idle`.
- **كارت التعريف (`found`):** مربع أيقونة check أخضر صلب + "تم التعرف على الشركة" + اسم الشركة (`h3`) + "الخدمات المتاحة" كشارات (الحضور/الإجازات/كشف الراتب حسب المفعّل) + سطر أمان "لن نطلب الكود مرة أخرى على هذا الجهاز".
- **البيانات:** `CompanyRegistry.resolve(code)` يرجع `Company(code, name, apiBaseUrl, features)` أو يرمي `CompanyNotFoundException` / `CompanyRegistryUnavailableException`. الافتراضي `MockCompanyRegistry` (الأكواد التجريبية: `LOCKSYS` ← حضور + إجازات + راتب، `DEMO` ← حضور + إجازات). **للربط الحقيقي:** اكتب implementation يكلم السيرفر المركزي وحقنه في `LockSysApp(registry: ...)`.
- **الحفظ:** `CompanyStore` (SharedPreferences، المفتاح `company`). `apiBaseUrl` هو أساس كل نداءات الـ API بعد كده، و`company.has(AppFeature.x)` يحدد الشاشات والتابات المعروضة (طبّقه في `HomePage` عند ربط المزايا).
- **تغيير الشركة لاحقًا:** غير محدد بعد. لو اتقرر، أضف `CompanyStore.clear()` كإجراء في حسابي أو رابط صغير في شاشة الدخول.

## تسجيل الدخول — `LoginPage`
- **Hero أبيض** (تدرج Blue50→أبيض + Pattern L بتلاشي): زر اللغة أعلى النهاية، اللوجو (104)، "LockSys HR"، سطر وصف.
- تحته: Kicker "مرحبًا بعودتك" + H1 "تسجيل الدخول" ← حقل المستخدم/رقم الموظف (`mono`، أيقونة user) ← كلمة المرور (أيقونة lock + زر إظهار/إخفاء بالـ eye) ← صف "تذكرني" و"نسيت كلمة المرور؟" ← زر `lg` "دخول" (`loading` أثناء الطلب) ← زر ghost "الدخول بالبصمة".
- التحقق: المستخدم مطلوب، كلمة المرور مطلوبة و6 أحرف على الأقل، والأخطاء تحت الحقول بلغة الواجهة.
- الظهور المتتابع `AppReveal`. لوحة المفاتيح تُغلق بالسحب أو اللمس خارج الحقول.
- **الربط الفعلي**: استبدل التأخير الوهمي في `_submit` بنداء الـ API، وعند الفشل `AppSnackbar.show(..., tone: AppTone.danger)`.

## الرئيسية (تابات)
`AppScreen(bottomBar: AppBottomNav, ...)` بـ 4 تابات: الرئيسية · الحضور · الإجازات · حسابي.
Top bar: اللوجو (`AppLogoMark`) + "LockSys HR"، وأيقونة الإشعارات. Header: Kicker "صباح الخير" + الاسم + التاريخ.
المحتوى: كارت Navy واحد (الحضور + زر "تسجيل حضور") ← شبكة كارتين للأرقام ← عنوان "خدمات سريعة" + `AppListGroup`.
كل تاب يحتفظ بحالته (`IndexedStack`).

## قائمة (موظفون، طلبات، سجل...)
`AppScreen(showBack, body: ...)`: `AppPageHeader` ← بحث (`AppTextField` بـ `prefixIcon: search`) ← `AppChipRow` للفلاتر ← قائمة (`AppListGroup` أو `ListView`) ← FAB للإضافة إن لزم.
حالات إلزامية: `AppSkeletonList` أثناء التحميل · `AppEmptyState.empty` عند عدم وجود نتائج (مع "مسح الفلاتر" إن كان فيه فلتر) · `AppEmptyState.offline` عند الفشل · سحب للتحديث (`onRefresh`).
الفلاتر المتقدمة في `showAppBottomSheet` بزرين: "مسح" (ghost) و"تطبيق (N)".

## نموذج (طلب إجازة، إضافة موظف...)
`AppScreen(showBack, kicker, heading, subtitle, children: [...])`.
- تنبيه معلومات في أول الشاشة إن لزم (`AppAlert(info)`، مثل الرصيد).
- الحقول واحد تحت الآخر (الزوج القصير مثل "من/إلى" في صف بعمودين).
- التحقق يظهر تحت كل حقل، ولا تعطّل زر الإرسال بصمت.
- زر الإرسال `lg` في آخر المحتوى (أو `bottomBar` ثابت للنماذج الطويلة) مع `loading` أثناء الإرسال، ثم `AppSnackbar` للنجاح والرجوع.
- زر الإلغاء (ghost) اختياري تحت الزر الرئيسي.

## تفاصيل (كشف راتب، تفاصيل موظف)
`AppScreen(showBack, kicker, heading)` ← كارت Navy واحد للرقم/الحالة الأهم (`AppCard(navy)` + `AppBadge(solid)`) ← أقسام بعنوان `h3` وكل قسم `AppListGroup` (تسمية يمين، قيمة `mono` يسار) ← زر ghost للتحميل (`leadingIcon: download`).
المبالغ بـ `mono` وأرقام إنجليزية، والسالب بلون `danger`.

## حسابي
كارت Navy للملف الشخصي (أفاتار + الاسم + رقم الموظف) ← مجموعات بعناوين صغيرة (`AppGroupTitle`): الحساب، الأمان والتفضيلات، الدعم. كل عنصر `AppListTile` بـ `AppIconTile` (صف **اللغة** يفتح Bottom Sheet بخيارين عربي/English) ← زر ghost "تسجيل الخروج" (`leadingIcon: logout`) بتأكيد Dialog.

## حالة فارغة / خطأ / تحميل
لا تصمم من الصفر: `AppEmptyState.empty` · `AppEmptyState.offline` · `AppLoadable` + `AppSkeleton*`.
مع التحميل: ابنِ Skeleton بنفس أبعاد المحتوى (رأس + كروت + صفوف) ليحس المستخدم بأن الصفحة "جاهزة تتملّي".

## قواعد عامة للشاشات
- بنية ثابتة: Top bar → Header → المحتوى بمسافة 16 → (Bottom nav).
- كارت Navy واحد كحد أقصى.
- لا Dialog إلا للتأكيد الخطير. الفلاتر والاختيارات في Bottom Sheet.
- بعد أي إجراء ناجح: `AppSnackbar`. بعد الفشل: `AppSnackbar` بـ `danger` وزر "إعادة".
- الأرقام والتواريخ والأكواد `mono` LTR.
